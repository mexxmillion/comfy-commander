Custom nodes & worker connection
Install the listed nodes and their dependencies using the pinned runtime sources. Some need Commander's bundled patches or overlays; a plain upstream clone may not be enough. Restart ComfyUI and check again. Commander does not install or execute custom-node code from this page.

Cloud access
Connecting your Vast.ai or RunPod key automatically prepares a private worker SSH key on the computer running Commander. Both providers share it. Vast.ai also registers only the public half with your account. Nothing is rented during setup.
Sign in to check cloud access.
Advanced SSH setup
A dedicated private key stays on this controller. Existing keys are never overwritten. To use another pair, set CLOUD_SSH_KEY_FILE in the private .env and restart Commander. OpenSSH Client must be installed on this computer.

Use at least a 32k context window; 128k is recommended for workflows and media. Enter the context actually configured on the server, which may be lower than the model's advertised maximum. Creative batches can need up to 20,400 output tokens. These are Commander sizing recommendations, not universal model limits.
H3 enhancement with image references and Creative Engine image references require vision. H3 video/audio references additionally require the checked native media formats; ordinary OpenAI-compatible servers often do not accept video_url. Qwen rewriting and workflow review are text-only. Workflow review and Creative Engine need reliable JSON output. Unsupported media is blocked before transmission.
Prompts and supported references go to the chosen endpoint when you request AI assistance. OpenRouter and compatible-endpoint keys are separate and never forwarded to each other's endpoint.
